# Borgi Screen Catalog

Every screen should be designed for desktop and mobile where relevant. Admin screens use a light SaaS shell with rounded cards, subtle shadows, and restrained mascot placement.

## Marketing

### MKT-01 Landing
Hero, product preview, feature grid, how it works, use cases, testimonials, pricing preview, FAQ, final CTA, footer. Borgi points at a floating calendar and reminder bell.

### MKT-02 Features
Feature navigation and detailed sections for booking, calendar, reminders, CRM, staff, branches, reports, feedback, and integrations.

### MKT-03 Solutions
Industry-neutral use cases: clinic, salon, consulting, education, event, workshop, room, repair, and professional service.

### MKT-04 Pricing
Plan cards, monthly/yearly switch, comparison table, add-ons, FAQ. Borgi counts coins incorrectly with a confident expression.

### MKT-05 Integrations
LINE, email, SMS, calendar, meeting, payment, webhook, API, and automation integrations.

### MKT-06 About
Brand story, mascot story, mission, principles, and team.

### MKT-07 Contact / Demo
Lead form, date selection, contact channels, FAQ.

### MKT-08 Help Center
Search, categories, popular guides, contact support.

## Mandatory screen-state coverage

Each interactive screen must define loading, empty, error, disabled, permission-restricted, success, and mobile states. Forms must define validation, unsaved changes, and submission progress.
