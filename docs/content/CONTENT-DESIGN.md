# Content Design

Borgi copy is clear, supportive and action-oriented.

## Patterns

- Buttons use verbs: `Create booking`, `Save service`, `Send reminder`.
- Headings describe the current task or result.
- Empty states explain the next useful action.
- Errors state what happened, what remains safe and how to recover.
- Confirmations identify the affected customer, service, date or amount.
- Destructive actions use explicit labels such as `Cancel appointment`, not `Yes`.

Avoid blame, jokes during failures, vague labels, all caps, unnecessary exclamation marks and pet-related language. Keep technical identifiers available for support but secondary to human-readable explanations.
