# Empty-State Illustrations

Provide reusable scenes for no appointments, customers, services, staff, branches, notifications, reports, search results, feedback and payments.

Each scene contains one compact Borgi pose, one relevant prop and generous whitespace. The illustration supports the heading and action; it must not contain embedded UI text. Use transparent-ready composition and readable silhouettes at 160–320 px.

Copy pattern:

- Heading: state what is empty.
- Body: explain why or what happens next.
- Primary action: create, invite, add or adjust filters.
- Secondary action: learn more only when necessary.
