# Error-State Illustrations

Use Borgi as a calm helper for recoverable errors, offline states, expired sessions, missing permissions and unavailable services.

Visual rules:

- Concerned, never panicked or crying.
- One clear diagnostic prop such as a disconnected plug or paused clock.
- No red-dominant full background; reserve semantic red for the error indicator.
- Never hide the actual error message or recovery action inside artwork.

Error copy structure: what happened, what was preserved, what the user can do now and how to contact support when recovery fails.
