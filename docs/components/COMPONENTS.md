# Borgi Component System

## Foundations

- 4 px base spacing grid
- Content max width: 1280 px marketing, fluid admin shell
- Radius: 8, 12, 16, 24, pill
- Shadows: subtle only; no heavy neumorphism
- Motion: 120–240 ms for UI, 400–800 ms for mascot accents

## Status colors

Status must always include text or an icon, not color alone.

- Confirmed: success
- Pending: warning
- Completed: info or success
- Cancelled: neutral/error
- No-show: error
- Waitlisted: lilac
- Follow-up: orange

## Mascot usage inside components

Use Borgi in empty states, onboarding, educational callouts, celebration, system errors, and occasional dashboard greetings. Do not place Borgi in every card or row. Mascot artwork must never reduce data density or block a primary action.
