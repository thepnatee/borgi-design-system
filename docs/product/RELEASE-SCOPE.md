# Product Release Scope

## Release 1 — Foundation
Brand, mascot, tokens, authentication, workspace onboarding, services, staff, branches and public booking.

## Release 2 — Operations
Calendar, appointment management, customer directory, reminders, resources, today view and operational dashboard.

## Release 3 — Commercial
Payments, subscriptions, invoices, coupons, cancellation fees, reports and exports.

## Release 4 — Growth
Feedback, campaigns, integrations, webhooks, API access, advanced analytics and multi-workspace management.

## Release gate
A release may ship when critical flows have automated tests, keyboard accessibility, responsive acceptance, observability, migration and rollback notes, support documentation and product analytics.
