## Roles

- Owner: full organization access
- Admin: all operational access except ownership transfer
- Manager: assigned branches, reporting, staff, and bookings
- Receptionist: bookings, customers, check-in, payment status
- Staff: own schedule and assigned customer details
- Analyst: reports and exports only
- Viewer: read-only selected areas

## Responsive strategy

- Desktop: persistent sidebar, multi-panel calendar and detail drawer
- Tablet: collapsible sidebar, two-column layout
- Mobile admin: bottom navigation, one task per screen, bottom sheets
- Customer booking: mobile-first, sticky summary and primary action

## Accessibility

- WCAG AA contrast for all functional text
- Visible keyboard focus
- Minimum 44 x 44 px touch targets
- Status never conveyed by color alone
- Reduced-motion mode for mascot animation
- Descriptive alternative text for every meaningful illustration
