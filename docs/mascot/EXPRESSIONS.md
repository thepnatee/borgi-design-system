# Borgi Expression System

## Core expressions

| Expression | Visual cues | Product use |
|---|---|---|
| Neutral | asymmetric eyes, relaxed mouth | default helper and onboarding |
| Happy | tiny tongue, lifted cheeks | success and welcome |
| Thinking | raised brow, slight head tilt | tips, search and processing |
| Concerned | softened eyes, closed mouth | warnings and recoverable errors |
| Celebrating | open smile, lifted paws | completed booking or payment |
| Sleepy | half-closed eyes | quiet hours and no activity |

## Rules

Keep Borgi lovable and calm. Do not use anger, fear, crying, threatening teeth or extreme distress. Error states should communicate support rather than blame. Expressions must preserve the asymmetric eyes and compact facial proportions.
