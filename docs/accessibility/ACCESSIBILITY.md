# Accessibility Standards

Borgi targets WCAG 2.2 AA for customer and admin experiences.

## Required

- Keyboard access for every interactive element
- Visible focus indicators with sufficient contrast
- Semantic headings, landmarks, labels and error associations
- Minimum 44×44 px touch targets where practical
- Text contrast of at least 4.5:1 and non-text contrast of at least 3:1
- No state communicated by color alone
- Reduced-motion support
- Screen-reader announcements for async success, errors and loading completion
- Accessible names for icon-only controls
- Correct locale, language, date and currency output

Mascot and decorative illustrations use empty alternative text. Informative artwork receives a concise description, while all critical state and actions remain available as real text.
